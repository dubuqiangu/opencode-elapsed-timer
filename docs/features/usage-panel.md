# /usage-full 统计面板

开关式侧边栏面板(`session.panel` slot 贡献,面板名 `usage-meter.stats`)。命令同时进命令面板("用量统计(面板开关)")。

## 操作

| 键/命令 | 动作 |
|---|---|
| `/usage-full` 或 `Esc` | 开 / 收起 |
| `f`(面板聚焦时) | 全屏展开(窄终端下宿主自动全屏) |
| 面板打开期间 step 结束 | 自动刷新今日 + 全量明细 |

## 面板内容

**头部(随 500ms 时钟实时)**:当前会话计时/tok/s/今日 Σ。

**当前窗口** — 最后一次请求的 in/out/reasoning/cache 分项 + 占用% + ≥80% 压缩预警(`▲ 接近压缩阈值`);与原生侧栏面板同源同数。

**本会话累计** — 权威 `session.tokens` 聚合(免疫消息窗截断)+ 轮数(截断时标 `N+`)+ 会话级命中率 + 费用(cost 为 0 时整列隐藏)。

**子代理** — `parentID` 委派树 BFS 归总(上限 200)+ 会话与子代理合计;全部子会话零用量时整块隐藏;渲染时对每个子会话触发一次性 `session.sync()` 防陈旧。

**明细表** — 今日按模型明细(按输出排序)+ 今日合计(含命中率)+ 近 7 日 steps 趋势 + 累计总量 + 累计 Top 5 模型。

## 降级

无侧栏(会话外)自动降级为普通弹窗;会话内的降级弹窗同样展示当前窗口/本会话/子代理三块。stats API 不可用时弹窗显示错误文案,计时/tok/s 主功能不受影响。

## 口径说明

面板**始终完整展示**今日与当前会话两个命中率维度,不受 footer 配置影响;三口径(今日 Σ / 会话累计 / 窗口占用)对照表见 [architecture/usage-statistics.md](../architecture/usage-statistics.md)。
